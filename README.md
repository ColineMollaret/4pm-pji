# Petrophysical Joint Inversion

## Acknowledgement & citation

**This Renku project has been developped by Coline Mollaret (University of Fribourg).**

This is mainly based on the package pyGIMLi (https://www.pygimli.org/, Rücker et al. 2017), on the Petrophysical Joint Inversion framework developped by Wagner et al. (2019), and on further developement published in Mollaret et al. (2020). Please at least cite these papers if you use anything linked with them.
Further improvement have been performed by the Cryospheric Geophysics research Group of the University of Fribourg.

**This material has been developped for the GEOFCAN 2025 workshop (Avignon). All rights reserved.**

## Introduction

This is a Renku project - basically a git repository with some
bells and whistles. You'll find different folders like `data` and `notebooks` directories and
a `Dockerfile`. Do no tough the files Dockerfile, environment.yml and requirements.txt except if you know what you are doing.
