# 4pm-pji
PJI Notebooks mainly based on package pyGIMLi (www.pygimli.org/, Rücker et al. 2017), on the Petrophysical Joint Inversion framework developped by Wagner et al. (2019), and on further developement published in Mollaret et al. (2020). This material has been developped by Coline Mollaret (UNIFR) for the GEOFCAN 2025 workshop (Avignon, France).
